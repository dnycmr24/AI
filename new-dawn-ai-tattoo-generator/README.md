# NEW DAWN AI Tattoo Generator

Echte KI-Bildgenerierung für Tattoo-Motive.

## Wichtig

In Vercel muss diese Environment Variable gesetzt werden:

OPENAI_API_KEY=dein_api_key

## Deployment

1. ZIP entpacken
2. Dateien in Vercel/GitHub hochladen
3. Framework: Other
4. Build Command leer lassen
5. Output Directory: public
6. Environment Variable OPENAI_API_KEY setzen
7. Deploy / Redeploy

Die App ruft /api/generate auf und erzeugt echte Tattoo-Bilder über OpenAI.
